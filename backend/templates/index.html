Flask API Tester

Test your local Flask endpoints easily with customizable hosts and real-time responses.

CORS Warning for Local Testing:

If requests fail with a network error, ensure your Flask backend has CORS enabled! Install `flask-cors` (`pip install flask-cors`) and add `CORS(app)` to your main Flask code.
